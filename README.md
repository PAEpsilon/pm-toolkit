# PM Toolkit

Herramientas gratuitas y en español para Product Managers y equipos de producto.

- **Gratis y sin registro**
- **Privadas:** todo funciona en tu navegador; tus datos no se envían a ningún servidor.

## Herramientas

| Herramienta | Descripción |
|---|---|
| [Lean Inception](lean-inception/) | Las 9 actividades de una Lean Inception (método de Paulo Caroli): visión, es/no es, objetivos, personas, funcionalidades, revisión técnica/negocio/UX, recorridos, secuenciador con validación de reglas y Canvas MVP. Exporta a Markdown y JSON. |

## Uso en local

No hace falta instalar nada: abre `index.html` en el navegador.
